# Seek AI (Perplexity Clone)

Seek AI is a high-performance, full-stack AI-powered search and chat application inspired by Perplexity AI. It combines a modern, premium user interface with robust backend architecture to deliver real-time intelligent responses.

## 🚀 Features

- **Advanced AI Chat Interface:** Premium glassmorphism design with a dynamic, responsive UI.
- **Multiple AI Providers:** Seamless integration with leading AI models (OpenAI, Anthropic Claude, Google Gemini, Groq).
- **Tabbed Navigation:** Organized interface with Home, Discover, and Library tabs.
- **Syntax Highlighting:** Code blocks within AI responses are elegantly formatted and highlighted.
- **Secure Authentication:** User signup and login functionality.
- **Persistent Chat History:** Conversations are saved to the database and can be retrieved later.

## 🛠️ Technology Stack

**Frontend:**
- React.js (via Vite)
- Vanilla CSS (Custom modern styling, Glassmorphism, animations)
- React Router DOM

**Backend:**
- Node.js & Express.js
- MongoDB (Mongoose)
- RESTful APIs

**AI Integrations:**
- Groq / OpenAI / Gemini APIs
